## Design Specificity Verdict
Category-interchangeable: GitHub Primer palette near-verbatim; stock top bar + tree + table + ghost icons + drawer; stock admin tabs/cards/stat tiles. Brand gradient only in the 28px mark; site name replaces "h6ai". "Huge files, fast" has no UI expression.
Detector: page.php/PHP clean; js/lib 5x broken-image (false positives, runtime src); build adds side-tab (false positive, blockquote rule). Overlay (6 states, bypassCSP): dark-glow everywhere (false positive, overlay's own style), low-contrast (#6e7681 on #151b23 3.77:1; light 3.24:1; placeholders #757575 4.11:1; chips 4.07-4.42:1 at 12px) confirmed, flat-type-hierarchy in admin (14/16/18px) confirmed. B also found: preview dialog does not trap Tab; lolight style injection CSP error on every listing page.

## Priority Issues
- [P1] Download moment unguarded and unacknowledged: size-labelled per-row download control, name click = preview/open, post-start toast (size, resumable, copy direct link), labelled archive button with preparing state. (/impeccable shape)
- [P1] Phones lose facts and tools: size/date hidden below 420px; checkboxes opacity 0 on touch (layout.css hover:none rule overridden by view.css); 34px rows, 18px checkboxes; drawer without scrim/close; filter hides breadcrumb. (/impeccable adapt)
- [P1] Admin access control invites mistakes: .field input styles leak to checkboxes (663x36 role boxes); rule path defaults to "/" + Everyone none; 4-tab split without effective-access preview; anon without groups shows blank. (/impeccable harden)
- [P2] Wayfinding/recovery dead ends: hostname parent row, pathless search results, bare hints, invisible tab stops, no focus trap in preview, no h1, hints not live regions. (/impeccable clarify)
- [P2] Brand and product promise barely present: Primer palette, wordmark hidden/replaced, no bytes-served stat. (/impeccable bolder)
