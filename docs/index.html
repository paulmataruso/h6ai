h6ai

h6ai turns a folder on your server into a web page where people browse, search, preview and download your files. It is a fork of h5ai, updated for PHP 8.2 and later, with h5ai’s known security problems fixed and access control added.

Install

There are three ways to install h6ai, all with the same features. They differ in what they set up for you. Each has a step-by-step guide.

Native

nginx and PHP-FPM come from your distribution’s packages, on bare metal or a VM. install.sh gives h6ai its own PHP-FPM pool and system user.

Systems
Debian 12 and 13, Ubuntu 22.04, 24.04 and 26.04, Rocky, Alma and RHEL 9, Fedora 44, Alpine 3.22. Each one is tested: the installer runs in a clean container, then the full integration suite runs against the result.
You need
root, internet access for the package manager, and a free port (80 by default).
Shell, as a user with sudo
curl -LO https://github.com/paulmataruso/h6ai/releases/download/v1.0.0/h6ai-1.0.0.tar.gz
tar xzf h6ai-1.0.0.tar.gz && cd h6ai-1.0.0
sudo ./install.sh --native

The installer checks that PHP has the fix for CVE-2026-109618, creates the first admin and prints the URLs. Run it again to upgrade; --uninstall removes it.

Native install guide

Docker

One container with its own nginx and PHP-FPM. The folder you share is mounted into it from the host.

You need
Docker Engine with the Compose plugin, a free port, and about 600 MB for the image.
With the installer from the release
tar xzf h6ai-1.0.0.tar.gz && cd h6ai-1.0.0
sudo ./install.sh --docker --root /srv/files --port 8080
Or with compose, from a git checkout
git clone https://github.com/paulmataruso/h6ai.git && cd h6ai
cp .env.example .env    # set H6AI_FILES (the folder to share) and H6AI_PORT
docker compose up -d --build
docker compose logs h6ai | grep -A2 "first admin"

The first start creates an admin account and prints its password to the log, unless you set one in .env.

Docker install guide

Drop-in

The h5ai way: unzip _h6ai into the web root of the nginx and PHP you already run, add one line to the server block, and finish the setup in the browser. No installer and no shell needed.

You need
nginx with PHP-FPM 8.2 or later (gd and mbstring), a server block of its own, and a folder for your files outside the web root.
Shell, or upload the folder by FTP
cd /var/www/html
sudo unzip ~/h6ai-1.0.0-dropin.zip
sudo chown -R www-data: _h6ai/private/data _h6ai/private/cache _h6ai/public/cache
nginx, in the server block
error_page 403 404 = /_h6ai/public/index.php;

Then open /_h6ai/public/. It asks for the files folder and a password and gives you a setup file to upload. Every request reaches h6ai first, so permissions, the download log and the HTML sandbox work as in the other two, and nginx still sends the big files.

Features

No app to learn and no account needed for public files: a URL is a folder.

Downloads

Every file row ends in a chip with its size. A file without a preview unfolds in place: Download with the size, the direct link, resumable curl and wget commands, and a QR code for phones.

Large files

nginx sends every byte (sendfile, Range, ETag) after h6ai has checked the permission. Multi-GB files resume and seek. Folders download as tar or zip archives, streamed with no temp files and no size limit.

Access control

Levels per folder (none, list, read, download) for roles, users and folder groups. Download-only accounts for clients. The rules also cover direct links, not just the listing.

Anonymous mode

No sign-in anywhere in the listing: everyone browses and downloads everything except the folders you exclude.

Previews

Images, video, audio, text, code and markdown open in a preview. Thumbnails for images, video and PDF.

Finding files

Breadcrumb, folder tree, filter for the current folder, and an optional recursive search with time and result limits.

Themes

Five dark themes: Midnight, Graphite, Deep Sea, Ember and OLED Black, each checked for WCAG AA contrast. The admin sets the default; visitors can pick their own.

Activity log

Downloads, archives and logins with user, address, path and size, filterable on the admin page.

Google

Search Console, Tag Manager and GA4 from a pasted snippet. Generated robots.txt and sitemap.xml. Downloads can be reported to GA4 from the server, so direct links and curl count too.

Reverse proxy

Set the public address and the trusted proxies on the admin page; logs and rate limits then see the visitor’s real address.

Everywhere

Keyboard navigation, phones, and a plain listing without JavaScript. The interface is translated into 35 languages; text added in h6ai falls back to English.

Coming from h5ai

h6ai started from h5ai 0.30.0 by Lars Jung, h5ai’s last version, from January 2021. A URL is still a folder, and the drop-in install still works the way h5ai’s did. What changed:

PHP7.0 and later8.2 and later
Web serverApache, nginx, lighttpd and othersnginx
Installdrop-innative installer, Docker or drop-in

Interfaceone light themefive dark themes, redesigned for phones and keyboards

To move an h5ai site: move your files out of the web root, unzip _h6ai in place of _h5ai and add the nginx line. Your file URLs stay the same. Moving from h5ai has the commands.

Security

The audit in docs/AUDIT.md reviews h5ai 0.30 and lists 18 findings: 5 high, 7 medium, 4 low and 2 informational. The high and medium ones are fixed in h6ai and covered by the integration tests. On top of that:

  • Passwords are hashed with password_hash, compared in constant time, and logins are rate limited per address. There is no default password.
  • Sessions start only at login, with HttpOnly and SameSite=Strict cookies, and end when a password or role changes.
  • A nonce-based Content-Security-Policy, CSRF tokens and origin checks.
  • HTML, SVG and XML files in the share are served with a sandboxing CSP, so they can’t run script as h6ai. This is also h6ai’s hardening against CVE-2026-10961, a Chrome for iOS sandbox escape through a crafted HTML page.
  • The installers check PHP for the fix for CVE-2026-109618, and h6ai refuses multipart request bodies.
  • No shell for anything a visitor can influence; thumbnails and searches have size, time and depth limits.

Please report vulnerabilities privately, not in a public issue. SECURITY.md describes the security model.
